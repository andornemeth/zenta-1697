# Zenta 1697

A Commodore 64 game in four acts about the Battle of Zenta (11 September 1697). Hungarian and English.

- `zenta2.d64` – disk image (`LOAD"*",8,1` then `RUN`)
- `zenta2.prg` – the same game as a single program file

Joystick in port 2, or W A S D + SPACE. Press H during play for help.
